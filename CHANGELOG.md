# Changelog

## 0.1.0

- Initial Vestara .NET SDK release.
- Added core server-side .NET telemetry SDK.
- Added crash and handled-exception capture.
- Added remote logging and breadcrumbs.
- Added durable offline queueing and bounded retry behavior.
- Added request correlation support.
- Added ASP.NET Core request/failure integration.
- Added deterministic backend-request start/completion evidence.
- Added ASP.NET Core exception correlation and safe route-template capture.
- Added support for Worker Services, Generic Host, console/server applications, and ASP.NET Core.
